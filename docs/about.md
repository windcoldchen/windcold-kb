# 關於本知識庫

> 知識不是靜態的資訊堆疊，而是一座持續灌溉與迭代的數位花園。

---

## 建置宗旨

本知識庫旨在：

1. **系統化歸納**：將分散於各處的學習摘要、技術心得與日常備忘進行結構化整理。
2. **易於檢索**：透過全靜態、低延遲、強大搜尋能力的 Material for MkDocs 介面快速查閱。
3. **完全自主掌控**：純 Markdown 檔案儲存，無專有資料庫綁定，配合 Git 進行版本控制。
